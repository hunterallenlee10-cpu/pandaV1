# Media page

The header's **Media** menu item (with Blog and Podcast under it) went nowhere: its own link was `#`. It now leads to
`/media/`, a page that sets the blog and the podcast side by side:

| Half | What it shows | Where it comes from |
| --- | --- | --- |
| Blog (light) | The newest post, large (picture, category, date, reading time, excerpt, author), and the three posts before it | The site's own feed, `site/feed/index.xml`, read when the page is built, so it always shows the newest post of the capture it is built from |
| Podcast (dark) | Panda Vision's newest episode in a player, and **how to watch**: on the page, on Apple Podcasts, or in any podcast app with the feed link | `podcast.json` in this folder |

Under the two halves, **every episode** sits in a row across the page; picking one plays it in the player. On phones
the halves stack (blog first), and the buttons at the top jump to either one.

The **Podcast page** (`/podcast/`) gets the same player. Its own player was PodOps' old embed address, which now
leads nowhere (the page showed an empty space), and its "Listen on Apple Podcasts" badge linked to a listing Apple no
longer has (`id1839234062`). The empty space is now a dark card with the newest episode in the player, every episode
beside it (they scroll beside the player when there are more than fit), and the ways to watch below; the badge leads
to the show's current listing. The rest of the page is as captured. Each build renders the card again, so new episodes
show up there too.

On every page, the Media menu item now links to `/media/`. On phones, where tapping Media opens its list, the list's
first entry (which said "Blog", the same as the entry below it) is now **Media Hub** and leads there too, the way
"About Us" heads the About list. On `/media/` itself, Media is marked as the current page.

The page is generated by `scripts/lib/media-page.mjs` from a built page (`/podcast/`), keeping its header and footer
and replacing everything between them; its title, description, canonical address, social tags and structured data are
its own. The Podcast page's card is rendered by the same module (`collectPodcastPage`). `MEDIA_PAGE=0` builds no
page and leaves the menu item and the Podcast page as captured.

## The podcast

Panda Vision is the company's video podcast. The episodes are hosted by PodOps; the show's feed is
`https://rss.mypodops.com/panda-vision.xml` and it is on Apple Podcasts as
[id1863717313](https://podcasts.apple.com/us/podcast/panda-vision/id1863717313).

- **Right here:** the player streams the episode's video file straight from PodOps (H.264/AAC MP4s, 1080p to 4K). It
  loads nothing until someone presses play. Each episode's poster is a still from its own video. If a device can't
  play a file, the player says so and links to the episode on Apple Podcasts.
- **Apple Podcasts:** a button to the show. Without JavaScript, each episode links to its own Apple Podcasts page.
- **Any podcast app:** the feed address, with a Copy button.

### Refreshing the episodes

`podcast.json` holds the show and its episodes; `podcast/` holds the cover art and a still from each episode. Both
are written by:

```bash
npm run media:podcast          # node scripts/tools/media-podcast.mjs
npm run update:site            # then rebuild /media/ and /podcast/ (or the full build: node scripts/03-build.mjs)
```

The tool reads the feed and Apple Podcasts' directory (it is the only part that uses the network; the build never
does), keeps each episode's summary (the feed carries transcripts in some places; those are skipped), and takes a
still from each new episode's video with `ffmpeg`, reading only the few megabytes it needs. A still is taken 120
seconds in; to pick another moment, set `"posterAt"` (seconds) on that episode in `podcast.json` and run the tool with
`--force`. `--feed=URL` and `--apple-id=N` point it at another show.

## Files

| File | |
| --- | --- |
| `podcast.json` | The show and its episodes (written by the tool above; `posterAt` can be edited by hand). |
| `podcast/` | Cover art, and each episode's still (`ep-N`, 1280 px) and its small copy (`ep-N-sm`, 480 px), in JPEG and WebP. |
| `media.css`, `media.js` | Styles and the script (no dependencies). Copied to `site/_custom/media/` by the build. |

The script adds the large play button, plays the episodes picked from the row, copies the feed link and eases the
sections in as they scroll into view. Without it, the player shows its own controls, the episodes open on Apple
Podcasts and the feed link can be selected. People who prefer reduced motion get no animation.
