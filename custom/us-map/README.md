# Animated "areas we serve" map

This folder holds the US map that replaces the live site's old map sections everywhere they appear:

| Where | What it replaced | Version |
| --- | --- | --- |
| The "Local East Coast Exterior Remodelers" band on `/`, `/about/`, `/faqs/`, `/roofing/`, `/commerical-roofing/`, `/gutters/`, `/solar/`, `/reviews/`, `/podcast/` | a screenshot of a Google Map with numbered bubbles (the bottom was cropped off on wide screens, and it was hidden on phones) | compact, on orange |
| The same band on `/siding/` (white version) | a second screenshot of the same map | compact, on white |
| `/past-projects/` | the "Projects \| Map" Google Maps widget, which loads every project from the site's WordPress API and cannot work in a static copy | large, interactive |
| `/service-areas/` (under "…work on properties throughout:") | the list of city sub-sites, removed earlier | large, interactive |

The pages are edited by `scripts/lib/customize.mjs` during `scripts/03-build.mjs`, so re-running the capture and build
reproduces them. Set `CUSTOM_US_MAP=0` to build the original sections instead.

## What it does

When the map scrolls into view it fades in on the whole US, glides to the Mid-Atlantic, lights up the states Panda
serves one after another, and drops in the local-office markers, which then pulse gently. Hovering, tapping or tabbing
to a marker shows its name; the large version adds state buttons that zoom the map and update the panel beside it.

- **No Google Maps, no API key, no requests to other servers.** The map is drawn in the page itself (SVG) from the
  US Census Bureau's state outlines (public domain), so it cannot break the way the old widget did.
- **Works without JavaScript** (it simply shows the finished map) and for people who have "reduce motion" turned on
  (no animation).
- Screen readers get a text description of the highlighted states and offices; the state buttons are real buttons.

## Files

| File | |
| --- | --- |
| `areas.json` | **The content: which states light up and where the markers go.** Edit this. |
| `us-map.css`, `us-map.js` | Styles and the small script (no dependencies). Copied to `site/_custom/us-map/` by the build. |
| `us-states.json` | State outlines, generated by `scripts/tools/us-map-geometry.mjs`. Do not edit by hand. |

The markup is generated by `scripts/lib/us-map.mjs`.

## Editing the areas

`areas.json` lists the highlighted states (`states`) and the markers (`areas`). The current markers are the local
offices listed on the site's Contact page. The Charlotte, NC and Tampa, FL offices are in the file but switched off
with `"hidden": true`; to show one, delete that line and add its state (`{ "code": "NC", "name": "North Carolina" }`)
to `states`. `origin` is the state the light-up wave starts from.

After editing, rebuild: `node scripts/03-build.mjs` (or the whole pipeline with `bash scripts/capture-all.sh`).

## Adding job numbers (left out for now)

Add `"jobs": <number>` to any entry in `areas` (and/or `states`) and rebuild. Markers with a number become bubbles
sized by their count, with the number inside; tooltips and the panel on the large map show the counts too.
