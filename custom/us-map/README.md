# Animated "areas we serve" map

This folder holds the US map that replaces the live site's old map sections everywhere they appear:

| Where | What it replaced | Version |
| --- | --- | --- |
| The "Local East Coast Exterior Remodelers" band on `/`, `/about/`, `/faqs/`, `/roofing/`, `/commerical-roofing/`, `/gutters/`, `/solar/`, `/reviews/`, `/podcast/` | a screenshot of a Google Map with numbered bubbles (the bottom was cropped off on wide screens, and it was hidden on phones) | compact, on orange |
| The same band on `/siding/` (white version) | a second screenshot of the same map | compact, on white |
| `/past-projects/` | the "Projects \| Map" Google Maps widget, which loads every project from the site's WordPress API and cannot work in a static copy | large, interactive |
| `/service-areas/` (under "…work on properties throughout:") | the list of city sub-sites, removed earlier | large, interactive |

The pages are edited by `scripts/lib/customize.mjs` during `scripts/03-build.mjs`, so re-running the capture and build
reproduces them. Set `CUSTOM_US_MAP=0` to build the original sections instead.

## What it does

When the map scrolls into view it fades in, lights up the 20 states (counting Washington, D.C.) where Panda has
completed jobs one after another, starting from Maryland, and drops in the local-office markers, which then pulse
gently. Each state is shaded by how many jobs were completed there (the darker, or on the orange band the whiter, the
more), with a scale in the legend. Hovering over or tapping a state shows its count; hovering, tapping or tabbing to a
marker shows the office's name. The large version adds a button per state that zooms the map and shows that state's
count and offices in the panel beside it, and the panel starts with the total (9,900 jobs).

- **No Google Maps, no API key, no requests to other servers.** The map is drawn in the page itself (SVG) from the
  US Census Bureau's state outlines (public domain), so it cannot break the way the old widget did.
- **Works without JavaScript** (it simply shows the finished map) and for people who have "reduce motion" turned on
  (no animation).
- Screen readers get a text description listing each state with its job count, and the offices; the state buttons
  are real buttons. On phones the buttons sit in one row that scrolls sideways.

## Editing the areas

`areas.json` lists the highlighted states (`states`, in the order their buttons appear on the large map) and the
markers (`areas`). The markers are the seven local offices listed on the site's Contact page (Laurel, Reston, Dover,
Marlton, King of Prussia, Charlotte and Tampa). `origin` is the state the light-up wave starts from. An area with
`"hidden": true` is not drawn.

How much of the country the map shows follows from the states: it frames the lit states, or, once they stretch across
most of the country (as now, from California to Massachusetts), the whole US map.

A state far from the others can be marked `"inset": true`: it is then drawn, with its offices, in a small framed
box in the map's bottom-right corner instead of making the whole map zoom out for it (which would squeeze the
Mid-Atlantic offices together). This was used for Florida while the map showed only the East Coast; no state needs
it now that the whole country is shown. On the large map, choosing an inset state highlights its box, and the box
steps aside while another state is zoomed.

After editing, rebuild: `node scripts/03-build.mjs` (or the whole pipeline with `bash scripts/capture-all.sh`).

## Job numbers

Each state's `"jobs"` is the number of jobs completed there (from the job records; 20 jobs with no address on file
are left out). To update them, change the numbers and rebuild; the total on the large map is their sum.

The shading comes from `"jobTiers"`: each number is where a band starts, so `[1, 10, 100, 500, 1000]` makes the
bands 1–9, 10–99, 100–499, 500–999 and 1,000+. The legend's labels are built from it. Up to five bands are possible
(the colours, `--pmap-t1` to `--pmap-t5`, are in `us-map.css`, one set for the white map and one for the orange
band). A state without `"jobs"` keeps the plain "served" colour, and without any job numbers the map goes back to
one colour with an "Areas we serve" key.

Job numbers can also go on the markers (`"jobs"` on an entry in `areas`): markers with a number become bubbles
sized by their count, with the number inside. The current numbers are per state, so the markers have none.
